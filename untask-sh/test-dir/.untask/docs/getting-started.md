# Getting Started

## Installation

Install via Homebrew or download from GitHub Releases.

## Quick Start

1. Initialize a project: `untask init`
2. Add your first task: `untask add "My first task"`
3. View tasks: `untask list`
4. Open the TUI: `untask`

## Project Structure

After init, your project will have:

```
.untask/
  tasks/       # Task markdown files
  docs/        # Project documentation
  attachments/ # File attachments
  config.yml   # Project configuration
```
