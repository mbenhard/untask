Let's say I create a task. I let the AI agent to process it and it will end in the review column with the agent summary. Then, if I'm not satisfied with the task, I send it back using kickback. The task UI and content get updated with my review note, which is correct. However, when I Let it process it with the AI again, it removes the review summary and it edits and scrapes the notes content of the task with its own message. The notes should not be touched by the AI at all. It's only for the human to use an elite. So we should somehow make rules to not do that and we should also at the same time enable us to uh make a proper thread or conversation or a task history inside of the task itself in case we do multiple rounds, revisions, or iterations of the task, or even maybe subtasks as we have support for that.
